# Diagrams

Authored in [D2](https://d2lang.com) rather than Mermaid. Source is plain text, so these live in
git, diff in review, and are regenerated by a command — a diagram that cannot be diffed silently
drifts from the spec. Rationale in [research.md R-007](../research.md).

| Diagram | What it shows | Read it when |
|---|---|---|
| [`race-condition.d2`](./race-condition.d2) | **EC-001 on two timelines** — why check-then-write fails and why the constraint does not | **Start here.** It is the whole argument |
| [`domain-model.d2`](./domain-model.d2) | Room ⟶ Booking, the invariant, each qualifier mapped to a clause of the constraint | Understanding the data |
| [`system-architecture.d2`](./system-architecture.d2) | Browser → Server Action → Drizzle → Neon, with the constraint as the trust boundary | Understanding the runtime |
| [`booking-flow.d2`](./booking-flow.d2) | Every path `createBooking()` can take, including all nine refusals | Implementing or reviewing the action |

Rendered output is in [`out/`](./out/) as both SVG (crisp, for the repo) and PNG (for slides).

## Regenerating

```powershell
d2 system-architecture.d2 out/system-architecture.svg
d2 domain-model.d2        out/domain-model.svg
d2 booking-flow.d2        out/booking-flow.svg
d2 race-condition.d2      out/race-condition.svg

# PNG for slides
d2 race-condition.d2 out/race-condition.png

# Live preview while editing
d2 --watch race-condition.d2
```

Layout engine and theme are pinned per file in a `vars.d2-config` block, so output is reproducible
without remembering flags. `--sketch` adds a hand-drawn look if you prefer it for a talk.

## Gotchas found while authoring these

Recorded so the next person does not rediscover them:

- **`constraint` is a reserved keyword** and cannot be used as a node id — it is the attribute name
  for columns inside `shape: sql_table`. Our constraint node is called `excl`.
- **Markdown tables need the long block delimiter.** A `|` inside `|md ... |` terminates the block.
  Use `|||md ... |||` for any block containing a table.
- **Notes in a sequence diagram must be declared as a child of an actor** (`db.note1: "..."`). A
  top-level object becomes another lifeline instead.
- **Some icons break PNG rasterization.** `dev/chrome.svg` contains a `<linearGradient>` that renders
  in SVG but fails PNG export. Icons verified working: `dev/postgresql`, `dev/react`, `dev/html5`,
  `dev/typescript`, `dev/nodejs`, `dev/github`. Much of the `essentials/` namespace returns 403.
- **Do not set `style.fill` on a `sql_table`** — it overrides row fills and makes the column text
  unreadable. Style the `stroke` only.
